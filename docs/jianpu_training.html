简谱听写

内置经典曲库，也支持粘贴自定义简谱。随机抽取一段播放，从「听走向」到「听唱名」再到「听写全谱」逐级进阶。

也可直接粘贴截图（Ctrl+V）
语法：1-7 唱名；# 升号、b 降号（如 #4）；高音点直接缀在音后（1̇，U+0307），低音点同样支持下加点（U+0323）， 亦兼容 1' / 1, 写法；- 延音；0 休止；| 小节线；空格分隔。默认 1 = C（C4）。

正确 0 / 0 ，正确率 -

解析曲谱后，点击「下一题」开始
